# 界面截图 v2（隔离实例 + 假数据）

全部是在隔离实例里截的：自己的数据目录、编好的一学期、本机的假模型服务，没有读任何真实账号。重截一条命令，见 `contest/video/demo/README.md`：

```bash
node contest/video/demo/run.mjs
```

## 规格

- 窗口内容逻辑尺寸 1600×1000，deviceScaleFactor 2，PNG 是 **3200×2000**，浅色主题。
- 截的是网页内容，不含系统标题栏和右上角的三个窗口按钮（那是系统画的）；顶上 40 像素是应用自己的标题栏区域，空着。
- 每张图有同名 `.json`：`elements` 里每一项是 `{ name, id, kind, text, x, y, w, h }`（`id` 就是 HTML 快照里的 `data-demo-id`），**逻辑像素、左上角为原点**，乘 `scale`（2）就是图上的像素。`kind` 是这一类元素的名字，`name` 带序号（`notice[3]` 是右栏第 4 条通知）。`note` 写着这张图是什么时刻。
- 演示里的「现在」是 **2026-10-21（周三）15:40**，秋学期第 6 周（双周）。所有「今天」「还有 8 小时」「3 小时前」都按这个时刻算，重截也一样。

常用的 `kind`：

| 页面 | kind |
|---|---|
| 校园事务 | `affairs.todo` 左栏、`affairs.feed` 右栏、`task` 作业卡、`task.due` 截止时间那一格、`task.hand` 卡片右边的按钮、`memo` 备忘录每一行、`memo.new` 新建、`feed.tab` 两个页签、`feed.filter` 筛选、`notice` 每条通知、`notice.meta` 来源和时间那一行、`notice.memo` 行右边的「加到备忘录」、`feed.more` 展开其余、`feed.folded` 收起的那一行说明、`refresh` 刷新 |
| 通知加到备忘录 | 同上，加 `menu`、`menu.item`（两个选项）、`toast` 顶上的提示、`memo.title`、`memo.prop`、`memo.body` |
| 日程表 | `grid` 整个格子、`grid.head` 每天的表头、`grid.period` 左边节次、`grid.day` 每一天那一列、`block` 课和考试和备忘的块、`pin` 截止卡、`grid.now` 现在那条红线、`plan.week` 周次 |

## 静态 HTML 快照（html/）

每张图都有一份同名的 `html/名字.html`，是截图那一刻的页面存成的独立文件：所有样式表（含引擎的设计变量和 @font-face 字体）合成一个 <style>，字体、图片换成 data URL，去掉了脚本；滚过的区域用 CSS `translate` 挪回当时的位置（容器上记着 `data-demo-scroll-top`），吸附在底部的输入框原样留着；讲解窗口的画布换成当时画面的图片（这一块是位图，其余都是矢量文字和 SVG）。每份 2.3–2.5 MB，讲解那份 0.2 MB。

- 用 Chrome 直接打开，或放进 1600×1000 的 iframe，和截图一样。
- 关键元素带 `data-demo-id`，和 `.json` 里每一项的 `id` 对应：类别里的点换成横杠，列表加序号，例如 `notice-3`、`task-1`（作业卡）、`memo-2`、`trace-row-5`、`trace-node-5`、`block-7`（日程表的块）。同一个元素属于两类时编号用空格隔开，选的时候用 `[data-demo-id~="notice-3"]`。
- 核对：`node_modules/electron/dist/electron.exe contest/video/demo/verify-html.cjs` 把每份 HTML 离屏打开、截图、和 PNG 逐像素比，结果在 `html/verify.json`：29 份里不同的像素都在 0.8%–5.2% 之间，看过对比图，差在文字抗锯齿（核对时按 1.5 倍渲染、截图是 2 倍缩下来的），版面、滚动位置、展开状态都一致。
- 快照是静态的：鼠标悬停样式还在，点击、滚动不会有反应。

## 截不到的

- **托盘提醒（tray）**：托盘图标闪烁和鼠标悬停的提示是 Windows 系统画的，不在应用页面里，调试协议截不到；要截只能对整个桌面截屏，会把开发机桌面上别的东西一起截进去，所以没截。需要的话在应用里发一条「提醒我……」的对话、把窗口切到后台，用系统截图工具截任务栏右下角。
