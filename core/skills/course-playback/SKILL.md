# 视频播放与诊断

复用用户的课程页；只有课名时，用 `zju` 的 `args: ["xuezai", "course", "view", "--course", "课程名"]` 取活动链接。同名先确定目标，不猜课程或活动编号。

- 有浏览器操作工具时，通过官方播放器设为用户要求的倍速（未指定时 2 倍），只读检查实际 `video.playbackRate` 与前后采样间位置是否增加。没有浏览器操作能力时，给出课程链接和操作方法，不改用终端连接浏览器。
- 已安装且明确支持 `courses.zju.edu.cn` 的 OCS 版本时，检查其「学在浙大 → 课程播放助手」配置。没看到面板时先检查注入与站点支持；本流程不附带、安装或注入 OCS，也不保证普通 OCS 版本已适配该站。
- 需要排查暂停或控件不匹配时，才读[浏览器诊断](references/browser.md)。只查询原因时先读状态，不自行开始播放。

手动暂停保持暂停；缓冲恢复最多两次，播放被拒或耗尽后交给用户处理。结束后只通过唯一、可见、启用的「下一个」按钮切课；进入作业、测试或活动已结束时停止。不改写进度、播放位置、完成状态或伪造事件。

联播依赖支持该站的脚本和打开的标签页；技能、诊断命令不会常驻。只报告真实观察到的结果，不能把静态暂停或无关网站错误当成已确定的根因。
