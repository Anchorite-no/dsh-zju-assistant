# 技能骨架和例子

## 骨架

照下面填。六个二级标题一字不差，存的时候会核对；某一节确实没有东西可写，也写一句为什么（「这件事没有要提醒的时间点」）。

```markdown
# 技能的名字

一段话：替用户办成什么，最后交给他什么。

## 什么时候用

- 用户会怎么说（三到五种）。
- 和哪些事容易混，混的时候用哪个（只问一个数的直接查，不启动这个技能）。

## 开始前

- 读什么（campus_profile_read 的哪条记忆、campus_context_read 的哪门课、campus_schedule_read 的哪几天、campus_note_read、schedule_list），读到什么就怎么走。
- 没有档案、没有记忆时怎么照样做。

## 步骤

### 1. 第一步
要什么、用哪条命令或工具、结果里哪一项交给下一步；如果……就……。

### 2. 第二步
……

### N. 写操作（如有）
交之前给用户看什么、等他说什么才做、做完怎么回查。

## 交付

交付物的格式（长的放 references/），存到哪，对话里怎么呈现。

## 做完以后

要提醒的时间点、要留下的结论、要更新的档案，每项先问用户，同意了用哪个工具。

## 出错和边界

这次碰到的失败和绕过的办法；参考文档里写着的常见失败；不做的事。
```

## 一个写好的例子

下面是「奖学金申请」的样子：一个学生走过一遍以后存下来的。注意三处：「开始前」写的是读哪里、读到什么怎么走，没有写死他的绩点；第 2 步把弯路变成了判断；「出错和边界」里是这次真碰到的事。

```markdown
# 奖学金申请

把一次奖学金或荣誉称号的申请从找通知办到材料备齐：找到适用的通知和细则，对照条件看够不够，把成绩单、二课记点证明和申请表整理成一份要交的 PDF。

## 什么时候用

- 「这次奖学金我能申请吗」「帮我准备奖学金材料」「评奖评优要交什么」「国奖的条件是什么」。
- 只问某个奖学金的金额或名额的，直接查通知回答，不启动整个技能。

## 开始前

- campus_profile_read：基础信息里的学院和年级决定看哪个学院的细则；记忆里的「目标与打算」写了保研的，把综合测评的计算口径放在最前面讲。
- campus_note_read：他记过的往年申请（交了什么、卡在哪）先看一遍，今年的材料清单拿去对照。
- 没有学院信息时先问他是哪个学院，不猜。

## 步骤

### 1. 找通知
`notice list --keyword "奖学金"` 和 `notice list --keyword "评奖评优"` 一起查。学院的通知常写成「评奖评优」「综合测评」，标题里不一定有「奖学金」三个字，只搜一个词会漏。只看本学年的。

### 2. 读细则
用 `notice view --url 通知链接` 读全文，附件里的细则用 `doc text --url 附件链接` 读。学校的通知和学院的细则说法不一样时，以学院细则为准，并把两处都告诉他。

### 3. 对照条件
`zdbk grades` 取成绩，`sztz credits` 取第二课堂的记点。逐条对照细则里的条件，表里写「满足 / 不满足 / 要他自己确认」（比如没有处分这一条查不到，只能问他）。

### 4. 整理材料
成绩单截图、证书照片和填好的申请表用 `doc pdf --file "文件1|文件2" --out 申请材料.pdf` 合成一份，顺序照细则里写的。

## 交付

一张条件对照表（条件、要求、他的情况、是否满足、出处）、一份材料清单（已备、缺的、在哪弄），和合成好的 PDF 的完整路径。

## 做完以后

- 细则里的截止时间：问他要不要建提醒，同意了用 schedule_create，截止前两天提醒一次。
- 问他要不要把材料清单加进备忘录，同意了用 campus_note_write，标题写「某某奖学金申请」，截止写进属性。

## 出错和边界

- 这次碰到的：学院的细则只有附件里的 Word，`notice view` 的正文里看不到条件，要去读附件。
- 成绩还没出齐时，对照表里那一栏写「成绩未出齐」，不按已出的算。
- 不替他填申请表里的个人陈述，可以帮他改。
- 申请表交到哪（学院邮箱、系统）照细则写；要发邮件的先给他看全文，等他同意。
```

## 水和不水的差别

同一步，两种写法：

| 水 | 不水 |
|---|---|
| 查询相关通知。 | `notice list` 用「奖学金」「评奖评优」两个词一起查，学院的通知常不带「奖学金」三个字。 |
| 读取用户信息。 | 读记忆里的「目标与打算」，写了保研的，先讲综合测评的口径。 |
| 注意处理错误。 | 细则只在附件 Word 里，正文里看不到条件，要用 `doc text` 读附件。 |
| 完成后告知用户。 | 交付条件对照表、材料清单和 PDF 的完整路径；截止前两天的提醒先问他要不要建。 |
