## 2026-10-09 实测结果

- `npm run typecheck` 通过；`npm run test:profile` 43 项通过；Python 采集器 7 组通过；`npm run package` 成功。
- 从插件列表打开详情，检查微信 4.1.15.13；空目录无链接按名称添加「浙大体育与艺术」成功。
- 实际库由之前的 79 篇增长至 80 篇。正式本地状态库同步返回 `newlyDiscoveredCount=1`，新文章「胡金秋领衔！全明星校园行即将登陆浙大！」显示在插件顶部。没有测量服务器送达延迟。
- 单号暂停/恢复、整体关闭/开启、手动刷新、文章筛选、无结果搜索、无效链接拒绝、同号链接重复添加及打开原文均通过正常控件操作验证。
- 整体关闭后添加和检查按钮停用，文章区隐藏；服务测试同时确认 API、助手工具和后台同步被阻断。单号暂停保留缓存。

- 深浅主题、原生桌面窗口以及 520×760 CSS 像素独立视口已检查。未发现关键控件重叠、横向溢出或不可读文字；长标题换行，添加列表可滚动。
