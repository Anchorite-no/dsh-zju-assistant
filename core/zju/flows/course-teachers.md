# 选课前比较教学班和老师

同一门课开了几个班时，把教务网、查老师和 CC98 三处的信息并到一张表里，由用户自己定选谁。这里只查不选；定下来以后怎么提交见 [本科选课](course-selection.md)。

## 1. 教学班

- `zdbk selection sections --course 课程名` 列出这门课的全部教学班：教师、时间、地点、考试时间、余量和容量。用户已经排除了某些时间的，加 `--time`。
- 和本人课表冲不冲突：`zdbk timetable`（有缓存，不会重复联网）。冲突的班在表里标出来，不直接去掉。

## 2. 老师

上一步的几位老师同时查，不要一位一位地等：

- `chalaoshi teacher --name 姓名`：评分、评分人数、点名比例、所教课程的平均绩点和评论。同名时加 `--college 学院`。
- `chalaoshi course --name 课程名`：教这门课的每位老师的平均绩点、标准差和样本人数。课程名要和查老师页面上的写法一样，不确定时先看上一条结果的 courses。
- 查老师连不上（返回 `TRANSPORT`）时照实说，不换别的站，接着做下一步。

## 3. 学长学姐怎么说

- `cc98 search --keyword "课程名 老师甲、课程名 老师乙、课程名 选课"`，几种说法一次给完。
- 挑标题对得上的帖子，用一次 `cc98 topic view --id "A|B|C" --find "老师甲、老师乙"` 只读提到这几位老师的楼层，不整帖通读。

## 4. 给出比较

一位老师一行的表：上课时间和地点、余量 / 容量、查老师评分（评分人数）、这门课的平均绩点（样本人数）、点名比例、CC98 上的说法（一句话，带帖子链接）、和课表冲不冲突。表下面注明：

- 样本少于 10 人的评分和绩点写「样本少」，不拿它下结论。
- 帖子是哪一年的。三年前的评价和现在可能不是一回事。
- 不替用户做决定。他问「你觉得选谁」时，按他在意的那一条（给分、点名、时间）说哪一位更合适、依据是表里的哪一栏。
