# 今日安排工作流

几个系统各查一次，同时发出，不要一个等一个。全部只读。

## 1. 查

- `zdbk timetable`：今天星期几、上哪些课、几点、在哪。按结果里的 currentTime 和周次（单双周）筛，不凭印象。
- 今天有实验课时再查 `lab timetable`：做哪个实验、在哪间实验室。
- `xuezai todos`：未交的作业和测验，按截止时间排。
- `pta homework list`：没截止的题目集里还没做完的。
- `zdbk exams`：七天内有没有考试。
- `notice new`：上次之后新发的通知，按标题挑和他有关的，再用一次 `notice view --url` 取全文；不逐条都取。

哪一个没查到（账号没填、系统打不开），在最后说明是哪个、什么原因，别的照常给。用户在「插件」页关掉的功能不查。

## 2. 排成一页

1. **今天的课**：一行一门，时间、课名、教室；实验课写实验名和实验室。没有课就写今天没课。
2. **要交的**：今天和明天截止的排最前，写具体日期和时间；一周内的列在后面；更远的只说还有几项。
3. **考试**：七天内的，写日期、时间、考场；考场没公布的写明还没出。
4. **新通知**：只列和他有关的，一条一句话加链接；没有就不写这一节。

只说查到的，一页放得下。

## 3. 定时发的时候

这份安排由定时任务到点发来时（见 [定时任务](../references/schedule.md)），做完用 campus_notify 提醒一句：标题写「今日安排」，内容写最要紧的一件，比如「上午两节课，数据结构的作业今晚截止」。
