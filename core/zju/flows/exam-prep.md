# 考前准备工作流

把分散在四处的东西并到一起：教务网的考试安排、智云录播里老师说过的话、学在浙大的课件、CC98 上往年的经验。只整理查得到的材料，不押题。

## 1. 什么时候考

- `zdbk exams --course 课程名`：期中、期末各自的日期、时间、考场、座位。`status` 是「未公布」就照实说还没出，不推测。
- 不指定课程时 `zdbk exams` 给出全部，按日期排，哪几门挨得近一眼看得出来。

## 2. 老师说过什么

- `zhiyun search subtitles --course 课程名 --keyword "考试、期中、期末、范围、重点、不考、题型、开卷"`，一次搜完全部录播。
- 每处命中带第几次课、时间点和前后一句。老师前后说法不一样时两处都列出来，以后说的为准。
- 学院或课程发过考试通知的：`notice list --keyword "课程名 考试"`。

## 3. 材料齐不齐

- `xuezai material list --course 课程名` 看每章有什么课件；本机还没有的，用 `xuezai material download --course 课程名 --chapter 章节名` 按章下。
- 往年卷、复习提纲这类老师放在平台上的也在这里。平台上没有的，不去别处找来源不明的「真题」。
- 这门课做过总结的课次，`总结.md` 里的「要点回顾」可以直接用。

## 4. 往年的经验

- `cc98 search --keyword "课程名 期末、课程名 复习、课程名 回忆卷"`，挑近两三年的帖子，用 `cc98 topic view --id "A|B" --find "题型、范围、重点"` 读相关的楼层。
- 只转述帖子里说的，带上帖子链接和年份；换过老师或改过大纲的，提醒一句未必还适用。

## 5. 排出来

给用户一页：

- 考试时间、地点，离现在还有几天（写具体日期和星期）。
- 老师明确说过的范围、题型和不考的内容，每条带出处（第几次课、几分几秒）。
- 按章列的复习清单：这一章的课件在哪、对应哪几次课、往年帖子里提到的重点。
- 从今天排到考前一天的安排。个人档案的记忆里他「还不熟」的部分多留时间；几门课挨着考时一起排。

他想把其中一章彻底弄懂，可以用 learn 技能做成讲解。要到点提醒复习，见 [定时任务](../references/schedule.md)。
