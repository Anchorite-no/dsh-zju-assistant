# 交作业工作流（学在浙大）

提交是写操作：交哪一份作业、交哪个文件，原样说给用户，等他明确同意再交。PTA 的作业不走这里，见 [PTA](../references/pta.md)。

## 1. 弄清交什么

- 用户没说是哪一份：`xuezai todos` 看未交的，按截止时间问他是哪一份。
- `xuezai homework view --course 课程名 --name 作业名`：完整要求、提交方式和次数、能不能撤回、已经交过什么。要求里写了文件名格式、文件类型、页数限制的，记下来，第 2 步照做。
- 老师随作业给了题目或模板：`xuezai homework attachments --course 课程名 --name 作业名` 下载，用 `doc text --file` 读。
- 已经截止、提交次数用完、只能在线作答的，到这里停下并说明，不往下走。

## 2. 准备文件

- 用户给的是照片、截图或 Word，而作业要 PDF：`doc pdf --file "第1页.jpg|第2页.jpg" --out 文件名.pdf`，按用户给的顺序排页。页序不确定时先问，不猜。
- 文件名照作业要求的格式（常见的是「学号_姓名_第几次作业」）。学号和姓名用 `zdbk student` 查；研究生查不到，问用户。
- 合成以后把页面渲染成图看一眼：页序、方向、有没有缺页、字看不看得清。
- 作业内容由用户自己完成。这里只整理、转换和检查格式，不替他写答案。

## 3. 确认后提交

1. 对用户说清：哪门课、哪份作业、几号几点截止、要交的文件（给出链接）和页数，等他说可以。
2. `xuezai homework submit --course 课程名 --name 作业名 --file 文件 --confirm`，设置 `ZJU_ALLOW_WRITE=1`。多个文件用竖线分隔；文字作业或留言用 `--comment`。
3. 结果里 `verified: true` 才算交上。不是的话照 message 说明，不重复提交。

## 4. 交错了

- 老师允许撤回：`xuezai homework retract --course 课程名 --name 作业名 --confirm`，撤回到草稿后重新走第 2、3 步。
- 不允许撤回但还能再交的，直接再交一次；次数用完的，请用户联系老师或助教。
