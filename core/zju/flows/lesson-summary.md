# 课后总结工作流（智云）

成品是这次课文件夹里的 `总结.md`。放对了，「学习」页那一次课上就有它；放在别处等于没做。

## 1. 找到这次课

- `zhiyun search lessons --course 课程名`：每次课是第几次、哪天、能不能回放、有哪些资源。用户说「今天的」「上周三的」，按日期对到第几次。
- 当天的课要课后才有字幕。还没有字幕又等不了的，走第 2 步的转写。

## 2. 取材料

- `zhiyun download --course 课程名 --lesson N --kind subtitles,ppt`。文件落在 `文档\CampusAgent\课程\课程名\第N次 日期\`，结果里有路径，不要另起位置。
- 这次课没有字幕（列在 `skipped`）：`zhiyun download --course 课程名 --lesson N --kind audio` 取音频，再 `zhiyun trans audio --file 音频`。一节课要几分钟，开始前说一声。
- 课件要文字用 `doc text --file 课件`；公式、图表、截图做的课件，把相关的页渲染成图来看。

## 3. 写

- 通读整节课的字幕，不只看开头。照 [笔记模板](../references/zhiyun-notes-template.md) 直接成稿，不先列提纲给用户确认。
- 作业、考试安排、点名、老师的更正放在最前面，带上是第几分钟说的。
- 小节按课上的先后排，标题后面写这一段在录播里从几点几分到几点几分。
- 专业词字幕常听错（「摊还」写成「瘫痪」），对着课件改；对不上的列进「待核对」，不猜。
- 不编造作业、题号、日期、公式和老师原话；课上没讲的不写。

## 4. 存和交付

- 存成这次课文件夹里的 `总结.md`（和 `subtitles.txt` 同一层）。已经有一份而且用户改过的，另存成 `总结-新.md` 并告诉他，不覆盖。
- 回答里给出文件链接，再用三五行说这次课最要紧的：有没有作业和截止时间、讲了哪几块。
- 用户想把这次课学懂、要带画面的讲解，那是 learn 技能的事（「课程讲解」插件）。
