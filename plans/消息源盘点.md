webplus 的统一规律（所有站通用）：

- 列表 `/<栏目>/list.htm`，第 N 页 `list{N}.htm`；页脚固定有 `<em class="all_pages">`、`all_count`、`per_count`。
- 文章 `/YYYY/MMDD/c<栏目id>a<文章id>/page.htm`，文章 id 全站群唯一递增（2026-09-30 已到 321 万），天然可做"上次看到哪"的水位线。
- 正文 `.wp_articlecontent`，附件 `/_upload/article/files/…`，PDF 有时用 `<div pdfsrc>` 内嵌（bksy.ts 已处理）。
- 列表项模板按站不同，目前见到 5 种：`li.right-list-item > a > p + span.y`（bksy）、`li.news > span.news_title a + span.news_meta`（libweb/xgb/office/itc）、`li > a + span.date`（ygb）、`li.news > a > div.news_meta > div.news_m + div.news_y`（dwzzb）、`li > a + 裸日期文本`（zhfw）。共同点：每项是一个 `<li>`，里面一个指向 `page.htm`（或外链）的 `<a>` 加一个日期。按这个共同点写一个解析器就够，不必每站一份。
- 需要登录的栏目统一表现为 302 到 `zjuam.zju.edu.cn/cas/login?service=http://<站>/<栏目>/list.psp`，交给已有的 `zjuam.loginService` 即可，不用每站写登录。

### 6.3 开发者平台上写的

- 应用接入：登录开发者平台 → 个人空间 → 我的应用 → 创建应用 → 信息技术中心审批 → 得到 appid、appkey 等；申请时可选开通统一身份认证。
- 开放 API 目录：接口访问凭证（`GET https://api.zju.edu.cn/api/reqtoken?appid=&appkey=`，token 一小时过期）、统一身份认证、浙大钉、身份服务、网站群、校园卡、消息通知、人像服务、任务中心、旧版 API 接入。各项正文没读。
- 轻应用：基于宜搭低代码，已搭 100 多个，点名的有访客预约、单位自招人员管理、出差请假审批、实验室管理、我的文艺生活、电动自行车管理；原文写适合一线老师搭建数据搜集、事项审批、资产管理。中间件九个：手机号获取、工号获取、三元组（人员、机构、岗位）、网站群信息发布、工作通知、任务服务、短信服务。
- AI 服务：给应用发大模型 token，接口有通用对话、文本嵌入、重排序。
