# ZJU All-in-One Assistant

浙大学生的一站式校园助手，装在 [DeepSeek Harness](https://www.deepseek.com/harness/) 里用。教务网、学在浙大、智云课堂、学习通、PTA、学校和学院的通知、二课、体艺场馆、CC98、浙大邮箱接到一起，问一句话，它去各个网站查好交给你。

> 学生个人项目，不是浙江大学的官方产品，和学校各系统的运营方没有关系。

## 装好以后

- 侧栏多三页：「校园事务」是作业、备忘录、校园通知和个人消息；「学习」是智云、学在浙大和超星的课件、录播；「日程表」把一周的课、考试、作业截止排在一张表上。
- 设置里多一页「个人档案」，放基础信息和记忆。
- 插件页里这一项下面有十个子插件，每个都能单独开关：

| 子插件 | 管的系统 | 默认 |
|---|---|---|
| 校园账号 | 统一身份认证、WebVPN；其余各项都靠它 | 开 |
| 课程与学习 | 教务网、学在浙大、PTA、大物实验课、智云课堂、学习通、电子书、知网 | 开 |
| 课程讲解 | 把一次课或一份资料讲成带画面的讲解 | 关 |
| 活动与场馆 | 素质拓展平台、体育场馆 | 开 |
| 校园社区 | CC98、查老师 | 开 |
| 校园通知 | 学校部门和学院官网的通知 | 开 |
| 浙大邮箱 | 浙大邮箱 | 开 |
| 微信聊天 | 本机微信的聊天记录，只能在 Windows 上用 | 关 |
| 钉钉聊天 | 本机钉钉的聊天记录，只能在 Windows 上用 | 关 |
| 微信公众号 | 微信读书里加了书架的公众号 | 关 |

## 开始用

1. 在「校园账号」的配置里填统一身份认证的学号和密码、WebVPN 的校园网账号；PTA、实验课、学习通、校园卡查询密码、CC98 在各自子插件的配置里填。
2. 模型在 DeepSeek Harness 的设置里配，登录 DeepSeek 账号或者填 API Key。
3. 跟助手说「帮我初始化校园档案」，它会把你的课程、平台入口和课程群整理好；不初始化也能直接问课表、作业和通知。
4. 要用微信公众号，再在插件页装一个 `dsh-builtin-browser`，扫码登录微信读书要用它开的浏览器。

选课、预约场馆、交作业、报名活动、发邮件这些会改动你账号的事，只在你明确要它做时才执行，执行前还要过一道 DeepSeek Harness 的批准。

## 数据

项目没有服务器，账号、档案和登录状态都存在你电脑上的 `~/.dsh/zju-campus`，账号文件没有加密，只用来登录学校的系统。对话内容会发给你在 DeepSeek Harness 里选的模型服务。

以前用桌面版（CampusAgent 0.1.7）的同学，两边的数据不通用，账号要在这里重新填一遍，浙大邮箱也要重新连接。
