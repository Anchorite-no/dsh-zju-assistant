# 自增长：对话后复盘（记忆和工作流补充）清单

2026-10-12 定的。目标：助手能不断长进，又不攒一堆垃圾。做法参照 Hermes 的结构（什么时候写、写到哪、怎么清各有各的机制），力度反过来：默认不写，有信号才写。

## 定下来的事（用户确认过）

- 对话里的助手**不再主动写记忆**，只在用户明说「记住」时写（技能里写明要记的那几步照旧，比如 learn 做完讲解补一行「看过的讲解」）。别的都交给对话结束后的复盘。
- 助手主动写的那条「大学物理（乙）Ⅱ」去掉（内容是作业怎么交，随时能查）。**做法是归档**：永久删除只有人能在页面上做。
- 这一期只做两类：**记忆**，和**工作流的补充**（flows，比如选课）。别的技能建议这一期不产生；`campus_skill_save` 照旧。
- 不改版本号、不打包、不提交，等用户说。仓库里同时有别的会话在改东西：提交时只加自己的文件，不用 `git add -A`。

## 离线试验得到的（做的时候要用）

- 模型 deepseek-flash，低档思考就够，高档反而更爱多写。每次约 5 千 token（规矩和技能目录放在系统提示里，能走缓存），多数 1 到 9 秒。46 次里 3 次网络错误，要带一次重试。
- 该不该写：第二版规矩 30 条用例跑 3 遍，26 条三遍一致，没有危险的写入。
- 内容上还会出的错（所以要代码把关）：
  - 删行会误删（把「第二讲的讲解还在做」删了）→ 自动的删除只认一种：把一个知识点从「还不熟」挪走。
  - 助手讲的话混进「他懂了什么」→ 依据必须是用户原话里能找到的；每行限长。
  - 依据字段会抄到敏感的话 → 依据只用来核对，不落盘、不进日志。
  - 新建和补充的界线不稳 → 这一期只有「补充已有的工作流」一种，目标必须是真有的工作流。
- 规矩里的例句和用例原话重合会让通过率虚高 → 正式的用例换一批措辞。
- 试验的脚本、用例和结果在这次会话的临时文件夹 `scratchpad/review/`（会话结束就没了；要用的已经搬进下面的文件）。

## 设计

**什么时候跑**：一次对话的一轮结束后，过一段时间（默认 10 分钟）没有新的一轮，就复盘一次。同一个对话后来又聊了，再复盘时只把新的几轮完整给它，前面的只给用户说过的话。子智能体的会话、没有用户发言的会话不看。应用退出时还没到点的，这一期不补（记在「没做的」里）。

**问模型一次，只出建议**：`ui/profile/model.mjs` 的 `askModel`，低档思考。输入是规矩 + 已有的工作流和它们的补充（系统提示）、已有的记忆全文 + 对话摘要（用户消息）。输出一个 JSON：最多两条记忆、一条工作流补充。

**记忆的条目固定成几类**：一门课一条（标题是课程名，标签「课程」，小标题用 learn 定的「学过」「还不熟」；「看过的讲解」是 learn 自己记的，复盘不碰）、「讲解偏好」、「目标与打算」、「个人背景」。条数因此有上限。

**代码把关**（模型的建议过不了就丢掉，并记进日志）：
- 依据的每一句都要是这次对话里用户原话的一部分。
- 标题在固定名单里，或者是已有的标题，或者是课程（标签「课程」）。已归档的不动。
- 新建的正文、每行补充都限长；一条记忆补到一定长度就不再加。
- 删除只认：这条记忆是助手写的、没人改过；被删的是「还不熟」下面的一行，原文对得上；同一条建议里同时有加的内容。别的删除一律不做。
- 有人改过的记忆只在末尾「助手补充」下面加，不动原文。
- 工作流补充：目标是 `core/zju/flows/` 里真有的；对话里有成功的校园命令；和已有的补充不重复；每个工作流有条数上限。

**写了要让人看见、能撤**：每次落盘记一条日志（什么时候、哪次对话、改了哪条、加了什么、改之前的全文）。设置的「个人档案」里列出最近整理的，每条能撤销；之后又被改过的不能撤，提示去直接改。同一页有开关，能关掉自动整理。

**工作流的补充放哪、怎么被读到**：存在档案目录（`profile/flow-notes.json`），不动安装目录。把它拼在 zju 技能正文的末尾交给引擎（`ui/profile/skills.mjs` 里技能的正文是我们给的），助手加载 zju 时就看到。记下补充时工作流文件的指纹；应用升级后正文变了，这条补充标成「工作流更新过，待核对」。插件页「技能」一组里能看、能删。

## 这一期不做的（记下来）

- 用量记录（每条记忆、每条补充被读了几次）和按时间归档。
- 应用升级后拿补充和新的工作流正文对一次、已经写进去的自动退掉（这一期只标「待核对」）。
- 应用退出时还没到点的对话，下次启动补上。
- 新建技能的建议、改助手存下的技能。
- 开发怎么看到用户机器上学到的东西。
- 多次对话累积以后记忆长成什么样，没有测过；条目太长时的合并。
